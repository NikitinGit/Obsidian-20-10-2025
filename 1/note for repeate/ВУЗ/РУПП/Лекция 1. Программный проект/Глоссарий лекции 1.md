# Глоссарий лекции 1
↑ [[1 Программный проект и его специфика]]

| Термин | Расшифровка |
|---|---|
| **Agile** | гибкие методологии: работа короткими итерациями с частыми выпусками и обратной связью |
| **API** | Application Programming Interface — интерфейс, через который программы обмениваются данными |
| **Burndown** | график сгорания: сколько работы осталось сделать |
| **C-level** | высшее руководство компании: CEO — генеральный директор, CFO — финансовый, CTO — технический |
| **CCPM** | Critical Chain Project Management — метод критической цепи: критический путь с учётом ограниченных ресурсов |
| **CMMI** | Capability Maturity Model Integration — модель зрелости процессов разработки |
| **CPI** | Cost Performance Index — индекс выполнения бюджета (>1 — экономим, <1 — перерасход) |
| **CPM** | Critical Path Method — метод критического пути: цепочка задач, задающая срок проекта |
| **CTO** | Chief Technology Officer — технический директор |
| **Cynefin** | модель Дейва Сноудена, делит ситуации по степени неопределённости |
| **DevOps** | Development + Operations — объединение разработки и эксплуатации для частых надёжных выпусков |
| **DoD** | Definition of Done — критерии готовности задачи |
| **DPA** | Data Processing Agreement — договор об обработке данных с провайдером |
| **EAC** | Estimate at Completion — прогноз итоговой стоимости проекта |
| **EMV** | Expected Monetary Value — ожидаемая денежная оценка риска (вероятность × ущерб в деньгах) |
| **EU AI Act** | Закон Евросоюза об ИИ (2024): классы риска ИИ-систем |
| **EVM** | Earned Value Management — метод освоенного объёма: сравнение плана, сделанного и потраченного |
| **IAM** | Identity and Access Management — управление учётными записями и правами доступа |
| **IRR** | Internal Rate of Return — внутренняя норма доходности проекта |
| **ISO 25010** | международный стандарт модели качества ПО |
| **ISO 27001** | международный стандарт информационной безопасности |
| **LLM** | Large Language Model — большая языковая модель (ChatGPT, Claude, GigaChat) |
| **ML** | Machine Learning — машинное обучение |
| **MVP** | Minimum Viable Product — минимально жизнеспособный продукт для проверки идеи |
| **NPV** | Net Present Value — чистая приведённая стоимость: выгода проекта с учётом обесценивания денег |
| **P×I** | Probability × Impact — вероятность × влияние, оценка серьёзности риска |
| **PM** | Project Manager — руководитель проекта (или project management — управление проектами) |
| **PMBOK** | Project Management Body of Knowledge — свод знаний по управлению проектами |
| **PMI** | Project Management Institute — Институт управления проектами |
| **PMO** | Project Management Office — проектный офис компании |
| **PO** | Product Owner — владелец продукта |
| **QA** | Quality Assurance — обеспечение качества, тестирование |
| **SOC 2** | американский стандарт аудита защиты данных у сервис-провайдеров |
| **SPI** | Schedule Performance Index — индекс выполнения сроков (<1 — отстаём) |
| **SSO** | Single Sign-On — единый вход во все системы |
| **UX/UI** | User Experience / User Interface — удобство использования / внешний вид интерфейса |
| **Velocity** | скорость команды: сколько работы делается за итерацию |
| **WBS** | Work Breakdown Structure — иерархическая структура работ |
| **44-ФЗ** | закон о государственных закупках |
| **152-ФЗ** | закон о персональных данных |
| **187-ФЗ** | закон о безопасности критической информационной инфраструктуры |
| **ИБ** | информационная безопасность |
| **КИИ** | критическая информационная инфраструктура (банки, энергетика, связь, транспорт) |
| **ПДн** | персональные данные |
| **СНиП** | строительные нормы и правила |
| **ТЗ** | техническое задание |
| **ФСТЭК** | Федеральная служба по техническому и экспортному контролю |
