# 1.4.3 Hard и soft skills
← [[1.4.2 Лидер-слуга]] · ↑ [[1.4 Роль руководителя проекта]] · [[1.4.4 Рабочий день и окружение PM]] →

> [!summary] Суть
> Руководителю нужны и измеримые инструменты (hard skills — «жёсткие» навыки), и навыки работы с людьми (soft skills — «мягкие» навыки).

## Что это
| Hard skills | Soft skills |
|---|---|
| Сетевое планирование: **CPM** (*Critical Path Method*, метод критического пути — поиск цепочки задач, задающей срок проекта), **CCPM** (*Critical Chain Project Management*, метод критической цепи — то же с учётом ограниченных ресурсов) | Активное слушание |
| Освоенный объём: **EVM** (*Earned Value Management*), **CPI** (*Cost Performance Index*, индекс выполнения бюджета: >1 — экономим), **SPI** (*Schedule Performance Index*, индекс выполнения сроков: <1 — отстаём), **EAC** (*Estimate at Completion*, прогноз итоговой стоимости) | Фасилитация (ведение встреч так, чтобы группа пришла к решению) |
| Управление рисками: **P×I** (*Probability × Impact*, вероятность × влияние), **EMV** (*Expected Monetary Value*, ожидаемая денежная оценка риска), метод Монте-Карло (моделирование тысяч случайных сценариев) | Урегулирование конфликтов |
| Финмоделирование: **NPV** (*Net Present Value*, чистая приведённая стоимость — сколько проект принесёт с учётом обесценивания денег), **IRR** (*Internal Rate of Return*, внутренняя норма доходности) | Эскалация без эмоций (передача проблемы на уровень выше) |
| Стандарты качества: **ISO 25010** (модель качества ПО), **CMMI** (*Capability Maturity Model Integration*, модель зрелости процессов разработки) | Презентации и переговоры |

## Зачем / с чем связано
Hard тренируются системно, soft — на ситуациях.

## Пример
Посчитать SPI = 0,8 (отстаём на 20%) — hard; сообщить об этом спонсору спокойно и с планом — soft.

## Проверь себя
*Сначала ответь вслух, потом раскрой вопрос.*

> [!question]- Назови три hard-навыка руководителя проекта.
> Например: CPM (критический путь), EVM (освоенный объём), управление рисками.

> [!question]- Что означает SPI меньше 1?
> Проект отстаёт от графика (SPI — индекс выполнения сроков).
