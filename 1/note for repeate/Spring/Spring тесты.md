> [!question]- Чем отличаются @Spy и @Mock?
> Spy по умолчанию выполняет реальные методы, mock — нет.
> `when(spy.method())` вызывает настоящий метод уже во время настройки заглушки. У обычного mock настоящий код не выполняется.

> [!question]- Как подменить метод spy без вызова настоящего кода?
> `doReturn(value).when(spy).method()` подменяет конкретный метод без его выполнения при настройке и последующих вызовах.

> [!question]- Когда нужно настраивать зависимости spy?
> До вызова настоящего метода, в том числе до `when(spy.method())`: метод выполняется уже при настройке и может обратиться к зависимостям. Например, сначала настроить `repository.save(...)`, затем — `when(spy.createReport())`.
> Для обычного mock такого требования при настройке нет. При `doReturn` настоящий метод spy тоже не выполняется, поэтому его зависимости для этого вызова настраивать не нужно.
