# Памятка: интервальные повторения для собеседования

## Зачем этот эксперимент

Нужно проверить, удобно ли повторять собственные вопросы прямо в Obsidian: сначала вспоминать ответ, потом открывать эталон и самому выбирать оценку. Если ответ не вспомнил — карточка должна появиться раньше; если вспомнил — позже.

Для проверки используется отдельная заметка [[Тест — Java карточки для повторения]]. Она помечена точным тегом `#flashcards`, поэтому при правильной настройке в тренировку попадут только эти две тестовые карточки. В установленной версии Flashcard Studio длинные карточки записываются как «вопрос», затем отдельная строка `?`, затем «ответ».

## Что установить

1. Откройте Obsidian → **Настройки** → **Сторонние плагины**.
2. Разрешите сторонние плагины, если Obsidian попросит подтверждение.
3. Нажмите **Обзор**, найдите **Flashcard Studio**, установите и включите его.
4. Если плагин не находится или требует более новую версию Obsidian, ничего массово не переносим: сначала сообщите об этом, и подберём альтернативу.

## Как провести проверку

1. Откройте заметку [[Тест — Java карточки для повторения]].
2. В Flashcard Studio найдите набор по тегу `flashcards` и начните повторение.
3. Проверьте, что вопрос виден, а ответ скрыт до вашего решения.
4. Сначала ответьте вслух или в черновике, затем раскройте эталон.
5. Если не вспомнили — выберите оценку, соответствующую **Again / Не вспомнил**. Если ответили верно — **Good / Вспомнил**.
6. Посмотрите, показывает ли плагин следующий срок повторения, затем закройте и снова откройте Obsidian: прогресс должен сохраниться.

## Что считаем успехом

- В очередь попадают ровно две тестовые карточки, а не все заметки собеседования.
- Полное условие задачи Stream API видно до раскрытия решения.
- Java-код хорошо читается.
- Оценка меняет срок следующего показа, а срок можно увидеть.
- Из очереди можно перейти к исходной заметке.

## Важные уточнения

- Открыть эталон — не то же самое, что автоматически проверить развёрнутый ответ. Итоговую оценку «вспомнил / не вспомнил» выбираете вы.
- Обычный режим интервальных повторений: верно отвеченные карточки не исчезают навсегда, а возвращаются через более долгий срок. Карточку обычно можно отдельно приостановить, если она больше не нужна.
- Уведомления на телефон и повторение карточек — разные функции. Их имеет смысл настраивать только после того, как сам эксперимент с карточками заработает.
